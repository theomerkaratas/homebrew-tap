# Homebrew tap for a22r

Install the Azure DevOps Batch Operator with:

```sh
brew install --cask theomerkaratas/tap/a22r
```

The `a22r` cask is generated and updated automatically by releases from
[`theomerkaratas/azure-devops-batch-operator`](https://github.com/theomerkaratas/azure-devops-batch-operator).
